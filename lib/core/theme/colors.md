# Identidade Visual

A identidade visual foi definida em uma abordagem mais underground, com estética quase monocromática e detalhes em carmesim para reforçar contraste, energia e destaque visual.

## Paleta principal

### Base escura
- Background: #080808
- Surface: #111111
- Surface Elevated: #181818
- Border / Divided: #292929

### Carmesim
- Crimson Primary: #CA2123
- Crimson Dark: #9E171B
- Crimson Deep: #640F12
- Crimson Soft: #913E40

### Textos e neutros
- Text Primary: #F0F0F0
- Text Secondary: #9E9D9D
- Text Disabled: #535353
- Icon Inactive: #7F8080

> Fluxo visual principal: preto, branco e carmesim.
